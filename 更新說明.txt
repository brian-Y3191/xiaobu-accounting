小布記帳本 V20 — 小票盒 CSV 匯入版

部署
1. 先在原 App 匯出完整 JSON 備份。
2. 將此資料夾八個程式檔案上傳原 GitHub Pages 位置並覆蓋：
   index.html、service-worker.js、manifest.webmanifest、icon-192.png、icon-512.png、app-update.js、receipt-import-core.js、receipt-import.js。
3. 等 GitHub Pages 部署成功。原 V19 的設定中按「檢查更新」，下載完成後先儲存帳目，再按「套用更新並重新開啟」。
4. 到設定確認「畫面 V20／離線快取 V20」。原網址、路徑及瀏覽器都保持相同，不需刪除 App。
5. 此程式包不包含你的私人 CSV 或帳目，不要把私人帳目上傳公開 GitHub 儲存庫。

使用
1. 設定 → 小票盒 CSV 匯入 → 選取 ReceiptBox.csv（原檔或 UTF-8 BOM 版皆可）。
2. 編碼通常保持「自動辨識」。日期和金額會自動讀取；逗號千分位能正確解析。
3. 確認開始／結束日期。預設包含所有有效日期；本次檔案含未來日期，照原日期保留。
4. 在「分類對照」修改每個來源分類的目標主分類、子項目。可從建議選單選取，也可輸入新名稱。
   同一來源分類會整批套用。可先不勾選不確定的分類，之後再讀同一原檔補匯。
5. 預覽待新增筆數、支出／收入及帳目。每頁 50 筆，可翻頁核對。
6. 可按「先匯出目前 JSON 備份」。勾選已核對，再按「確認新增帳目並記住對照」。
7. 原有帳目及設定保留。成功後分類對照保存在此 App 的本機資料，後續會自動帶入；JSON 備份也會包含對照。

預設建議（均可修改）
在外吃飯／飲料／食品 → 餐食／原分類名稱。
汽車／汽油／停車費／通行費／計程車等 → 交通／原分類名稱。
日用品／醫療／家居／管理費等 → 日常生活／原分類名稱。
服飾 → 衣服／服飾；禮金 → 贈禮／禮金。
甯甯的消費／小宇的消費 → 甯甯／小宇為各自主分類，子項目保留原分類名稱。
其他不確定分類，包含交際費、婚、改名、旅遊基金（兔）、出差換匯/隔離費用，保留原名稱供你確認。
如果 App 裡已有名稱相同的主分類或唯一對應的子項目，優先使用既有項目。
悠遊卡儲值、基金、換匯是否當成支出，請依你的記帳方式決定，可取消勾選。

資料處理
- 依「日期、分類、支出、收入」欄名讀取，不依欄位順序猜測。
- 日期、金額最多兩位小數；無效日期、負數、同列同時有收支等會列在錯誤清單，不匯入。
- 收支皆為 0 的列不建立帳目，可在零元列清單查看。
- 定位、註記、標籤1、標籤2會加上欄位名稱後放入店家備註，不會當成分類或遺漏。
- 原檔未提供幣別、分期期數或活動日，不自動推算匯率、不重複展開分期。
- 不把 CSV「收入」猜成薪資收入，可在對照中自行命名。
- 重複檢查根據原始日期、收支、金額、原分類及附註建立穩定識別碼；不依匯入後分類判斷。
- 同一原檔再次匯入會略過已匯入帳目；原檔中真的重複多筆仍會保留其筆數。
- 改動原始金額、分類、附註或增減完全相同的重複列，可能影響辨識。建議保留原檔，只在 App 中調整對照。
- 先前透過其他 JSON 或手動輸入的帳目，無法保證與 CSV 自動去重；請先挑選未匯入的日期區間。
- 若已成功匯入後想改對照，對照設定不會追溯修改舊帳。可使用 App 分類管理；或先還原匯入前備份，再用新對照重匯。
- 一次儲存成功才完成；若本機空間不足，取消本次新增並保留原帳目，可縮小範圍重試。

Excel 亂碼
本次原檔是無 BOM 的 UTF-8，中文本身正常。
另外提供的 ReceiptBox_Excel_UTF8.csv 僅在原始位元組前加 UTF-8 BOM，未改動欄位、資料、列順序或金額。
若直接開啟仍不正常：Excel → 資料 → 從文字/CSV → 選檔 → 編碼 65001/UTF-8 → 分隔符號「逗號」。
如需修改後另存，請用 CSV UTF-8；但整批分類對照建議直接在 App 裡設定，免得影響來源去重。
