小布記帳本 V22 — 搜尋位置與開始搬移按鈕調整

更新部署
1. 先在目前 App 的設定中下載完整 JSON 備份。
2. 將此資料夾內十個程式檔案上傳原 GitHub Pages 位置並覆蓋：
   index.html、service-worker.js、manifest.webmanifest、icon-192.png、icon-512.png、app-update.js、receipt-import-core.js、receipt-import.js、accounts-core.js、accounts-tools.js。
3. 等 GitHub Pages 部署成功，在原 App 設定按「檢查更新」，下載完再按「套用更新並重新開啟」。
4. 設定顯示「已確認：畫面 V22／離線快取 V22」才表示兩者一致。
5. 保持原網址、路徑及瀏覽器，不用刪除 App、不清除網站資料、不需重匯已存在的帳目。

第一頁快速搜尋
- 搜尋與結果放在「新增記帳 → 第1頁：選擇記帳地區」的「下一頁：開始記帳」按鈕下方。
- 若開啟 App 時直接進入收支輸入第2頁，按上方左側小圓點或「修改地區」返回第1頁，即可看到搜尋。
- 搜尋提供「日期、名稱／備註、類別／子項目」三個欄位。
- 可任填一個、兩個或三個欄位，填多個時需同時符合（AND）。
- 日期可輸入 2026、2026/11、2026/11/14，也接受 202611、20261114，或用 - 分隔。
- 名稱／備註可搜尋店家、備註、旅遊、分期名稱及收入名稱，支援部分文字。
- 類別／子項目可輸入部分名稱，例如「交通」或「洗車」。
- 有條件時搜尋全部歷史帳目，不受上方記帳日期限制；「清除條件」後恢復顯示上方日期的當日紀錄。
- 結果每頁 50 筆，可翻頁、點選帳目後編輯；顯示符合筆數與收支合計。
- 「批次整理帳目／帶入搜尋條件」會將這三個條件帶到整理工具。整理工具預設選支出，需要整理收入時請切換收支類型。

批次整理帳目
位置：設定 → 展開「批次整理帳目」，或由第一頁按鈕進入。
1. 篩選來源、收支類型、日期區間、名稱／備註、目前類別／子項目。
   可另外選「小票盒原始分類」。全部已填條件需同時符合。
   來源預設小票盒 CSV，也能選全部、手動、發票或其他來源。
2. 勾選個別帳目、「勾選這一頁」，或「全選符合結果」。
   全選符合結果會選到其他頁的符合帳目，畫面會顯示總筆數及金額。
   更改篩選條件會清除勾選，避免把不再顯示的帳目一起搬移。
3. 在「目標主分類」選既有名稱，或直接輸入新分類名稱。
4. 子項目可選：保留各筆原子項目、統一指定／新增、清空。
   選統一指定後，可直接輸入新子項目；確認時才建立分類及子項目，不需先到其他頁新增。
   收入只調整收入名稱，收入與支出分開整理。
5. 目標設定下方同時顯示「預覽搬移內容」及「開始搬移」。
   可以先預覽；預覽會自動捲到修改前後的位置，底下也有明確的「開始搬移 N 筆」。
   若勾到分期，會連同同組其他期數列入，預覽會明確顯示額外筆數。原分期名稱保留。
6. 按「開始搬移」會跳出確認視窗，顯示筆數、總額、新分類／子項目及額外分期期數。
   再按視窗中的「開始搬移 N 筆」才執行；按取消或 Escape 不修改帳目。
   不需要勾選原版預覽下方的確認框。單純篩選、勾選或預覽不會改帳。

例如：將舊小票盒「汽車」中備註含「洗車」的帳目搬移
- 來源：小票盒 CSV。
- 原始分類：汽車。
- 名稱／備註：洗車。
- 全選符合結果。
- 目標主分類：汽車（可新建）。
- 子項目：統一指定／新增 → 洗車。
- 按「開始搬移」，核對跳出視窗後再按「開始搬移 N 筆」。

保留資料與復原
- 搬移只調整所選帳目的分類與子項目。日期、金額、備註、收支類型、外幣資料與分期資料保留。
- 來源識別碼不變，搬移後重匯同一小票盒 CSV，仍能辨識先前已匯入的帳目。
- 搬移不追溯修改 CSV 匯入對照；後續新匯入帳目的對照仍在 CSV 匯入區設定。
- 每次成功搬移會保存一份精簡復原資料。可按「預覽復原上一次批次搬移」，核對後確認。
- 復原資料重新開啟 App 仍在，完整 JSON 備份也包含它。新的批次搬移會取代前一次復原紀錄。
- 復原只還原帳目的原分類、子項目與來源分類欄位；搬移時建立的分類及子項目會保留。
- 如搬移後相關帳目又被改分類、刪除、重排，為避免還原到錯誤帳目，可能會阻止復原。請保留操作前完整 JSON 備份。
- 後續新增在清單末端的帳目，不會被復原刪除；已修改的日期、金額與備註也不會被批次復原覆寫。
- 儲存失敗時，本次操作不套用，原帳目與前次復原紀錄保留。
- 新增「早餐」等分類不再於每次啟動時被舊分類遷移規則改回其他名稱。

沿用功能
V20 的 CSV 匯入、分類對照、UTF-8／Big5 辨識、日期金額解析、來源去重與備份功能保留。
V19 起的版本檢查、離線快取優先及手機寬度限制保留。

驗證範圍
- 搜尋確實位於第1頁的開始記帳按鈕下方，切換第2頁時隱藏，搜尋結果與搜尋欄同區。
- 搬移目標下方的直接開始按鈕、預覽後自動捲動與開始按鈕、確認視窗取消／執行、鍵盤焦點循環。
- 七種一至三欄搜尋組合、年月及完整日期、無效日期、條件帶入整理工具。
- 新分類／子項目、保留或清空子項目、收入整理、隱藏分類重新啟用。
- 跨三頁全選 125 筆、切換篩選清空勾選、預覽不寫入、預覽後資料變動時阻止套用。
- 分期整組預覽、儲存失敗取消、重新開啟後復原、復原衝突檢查。
- 以 13,046 筆有效小票盒資料測試，完整搬移 12,990 筆支出，於真實 Chrome 本機儲存成功，重新開啟後復原與原始帳目逐筆一致。
- V20 CSV 選檔與匯入回歸測試，重匯去重與金額不變；圖表、分期頁面無 JavaScript 錯誤。
- Chrome 手機尺寸模擬，320／393／768px 寬度沒有頁面水平溢出；搜尋與預覽畫面已視覺檢查。
- Service Worker 離線快取、限定範圍清理及版本回覆採模擬測試。
尚未在實體 iPhone／Android 或你的 GitHub Pages 上實測，請先備份再部署。
