小布記帳本 V19 — 部署及更新說明

1. 更新前，先在原版匯出完整 JSON 備份。
2. 將本資料夾內六個程式檔案全部上傳原 GitHub Pages 位置並覆蓋：
   index.html、service-worker.js、manifest.webmanifest、icon-192.png、icon-512.png、app-update.js。
3. 保持同一個網址、路徑及瀏覽器；帳目仍使用原本的 kj_db 本機儲存，不需重新安裝。
4. 等 GitHub Pages 部署成功後，在手機開啟原主畫面 App。
   V18 升 V19 的首次更新可能仍需有網路：若尚看不到 V19，關閉 App 再重新開啟。
   舊版沒有更新按鈕；必要時在同一瀏覽器開啟原網址並重新整理，再開主畫面 App。
   不要清除網站資料，否則可能失去帳目。
5. 開啟「設定」的「程式版本與更新」。
   看到「目前執行 V19」及「已確認：畫面 V19／離線快取 V19」才代表兩者一致。
   「新版已下載完成」代表尚未套用；先儲存帳目，再按「套用更新並重新開啟」。
6. V19 之後可按「檢查更新」；回到 App 時也會節流檢查。
   「檢查更新」確認的是已部署到 Pages 的版本，不是尚未部署成功的 Git commit。

變更
- 修正已有出國地區設定時，可能提前讀取尚未初始化的幣別常數而中斷啟動。
- 啟動改為使用版本快取，不等待網路；新版本完整下載後才可套用。
- 只重畫目前頁面；避免每次操作重畫所有清單、圖表及分期統計。
- 更新只清理本程式 xiaobu- 快取，不刪除其他程式的快取。
- 版本狀態比對畫面與正在控制 App 的 Service Worker。
- 固定裝置視窗寬度、禁止水平溢出，限制雙指縮放，輸入欄避免 iOS 自動放大。
- 保留上下捲動、底部導覽，以及記帳內「地區設定／收支輸入」橫滑換頁。

驗證範圍
已通過 JS 語法檢查、首次啟動／已有出國設定的模擬啟動、離線快取優先、快取清理範圍與版本回覆測試。
尚未在實體 iPhone/Android 或你的 GitHub Pages 上驗證。系統可能基於輔助使用設定允許縮放。

後續發版
每次發版須同步修改 HTML 版本、app-update.js 中版本比對字串、service-worker.js VERSION 與唯一 CACHE 名稱。
新增程式檔案也要加入 ASSETS。不可只替換 index.html 而沿用舊 CACHE。
