小布記帳本 V24 — QR Code 與拍照辨識匯入

部署更新
1. 先從原 App 匯出完整 JSON 備份。
2. 將本資料夾所有檔案，以及 vendor 整個資料夾，依原結構上傳原 GitHub Pages 位置。
   不要只上傳 index.html；OCR 引擎、繁體中文與英文模型都在 vendor 裡。
3. GitHub Pages 部署成功後，在原 App 設定按「檢查更新」，再按「套用更新並重新開啟」。
4. 確認顯示「畫面 V24／離線快取 V24」。保持原網址與瀏覽器，不刪除 App、不清除網站資料。
5. 部署包只有程式及模型，不含你的照片、會員資料、CSV 或帳目。

入口
底部新增「掃描匯入」頁，提供兩條路徑：
- QR Code 掃描：相機即時讀碼，或選取 QR 照片。
- 拍照辨識：直接拍收據，或從相簿選照片。
兩條路徑都先建立可編輯明細草稿，絕不自動入帳。
原本最上方的明細、第一頁開始記帳下方的搜尋，以及批次搬移功能保留。

QR Code
1. 使用 HTTPS 網址，按「QR Code 掃描」並允許相機。
2. 先掃臺灣電子發票左碼，再掃右碼；也可選一張同時包含兩碼的照片，或分別選左右碼照片。
3. 按「讀取 QR 明細」。必要時可展開暫存區，查看或貼上 QR 原文。
4. 支援國內 Big5、UTF-8、Base64 明細及境外電商格式的基本金額欄位；發票加密驗證不在本工具執行範圍。
5. QR 內容不一定完整，也可能未含折扣／點數折抵。會提示品項數不足或金額差異，不會自動從財政部平台查完整資料。
6. 換新發票前可按「清空 QR／下一張」。切換其他頁或 App 進背景會停止鏡頭。

拍照／選照片
1. 收據攤平，盡量正拍、光線均勻、避開陰影與反光；長收據請確保文字清楚。
2. 按「拍照辨識」或「選收據照片」，支援瀏覽器可讀的圖片，建議 JPG／PNG，檔案上限 20 MB。
3. 使用 Tesseract.js 6.0.1，在此裝置的瀏覽器執行繁體中文及英文 OCR；照片不送到雲端辨識。
4. 第一次需由本網站下載引擎與語言模型，約數 MB，手機可能需要一些時間。辨識有進度提示及取消按鈕。
5. 首次成功辨識後，已使用的引擎與模型會快取；已在 Chrome 測試離線重新開啟與辨識。
   瀏覽器可能自行清除快取，不能保證模型永久離線可用；需要時再次連網即可。
6. 辨識文字會顯示在「照片辨識原文」。可直接修改原文後按「從文字重建明細」，或在下方逐項修改。
7. OCR 並非萬用收據解析：會盡量讀取 Costco 數量×單價格式，以及常見「品名 金額」格式。
   品名、數字、日期、總額或折扣可能漏讀／讀錯，未讀出的項目可手動補上。
8. 缺少日期時必須自己填寫，不會悄悄用今天代替。無法判定的折扣不會擅自分配。

分類與確認
- 每個商品可修改品名、數量、單價、單價類型、額外折扣、主分類、子項目與備註。
- 主分類及子項目可以直接輸入新名稱，確認匯入時才建立。
- 分類建議以品名關鍵字及你先前確認的相同商品對照產生；不是雲端 AI 分類。
- 每個商品可取消勾選、移除，或手動新增商品。
- 獨立折扣列可修改金額及所屬商品；只有一個商品時會先建議配對，多商品不會憑猜測配對。
- 一次全單折扣請自己分配到各商品的額外折扣欄；不要同時保留同一筆獨立折扣，以免重複扣除。
- 「已折後售價」不能再次扣折扣，有衝突時會阻止匯入。
- 發票總額只核對，不另外建立總額帳目；優惠券也不另外記為收入。
- 商品加總不同於總額時，請補齊／修正；若只匯入部分商品，可明確勾選已核對差額。
- 最後勾選已逐項確認，再按「確認匯入 N 項商品」。
- 以相同發票號碼＋日期防止 QR 與照片重複匯入。沒有發票號碼時，只能依相同照片或原始文字做有限防重。
  同張收據重拍後照片識別可能不同，因此建議補填發票號碼。
- 同張發票的所有商品有共同關聯；沿用 App 刪除發票整組明細的功能。
- 成功匯入後回到記帳頁，顯示該日商品帳目。日期、品名、折扣與實付保留於帳目及備註。
- 照片與草稿不儲存在帳目資料中，未確認就重新整理頁面會清除草稿。

Costco 範例
威德益生菌：3 件 × 原單價 799 = 2,397。
優惠券：3 件 × 折扣 100 = 300。
商品入帳 2,097；折後單價 699。
備註保留原單價、原合計、折扣、折後單價與實付；不另記總額或信用卡付款。
本次提供的照片實測可讀出數量與單價／折扣，但品名與總額仍有誤讀。請人工校正後再確認。
若資料只給已折後售價，無法還原未知原價；請選「已折後售價」並依原始收據補充備註。

驗證
- 實際 QR 圖片同時解碼左右兩碼，建立三筆商品、總額不另記，重複匯入阻擋。
- 官方 QR 格式範例的字串解析、Base64 接續、單左碼不完整提示、日期與金額檢核。
- 實際提供的 Costco 照片在 Chrome 執行本機繁體中文 OCR，原文可修正，未確認前帳目數不變。
- 校正後 Costco 實付 2,097、折後單價 699、原價及折扣備註、既有帳目保留。
- 首次辨識後離線重開並再次辨識，沒有送照片到外部 HTTP 服務。
- 模擬相機啟動與換頁停止、320／393／768px 寬度、五個底部導覽同列、無 JavaScript 錯誤。
- 原搜尋位置、最上方明細、批次搬移及復原回歸測試。
尚未在你的實體手機鏡頭或實際 GitHub Pages 上驗證，請先備份再部署。
